# C-Note Music

Website for **Stevie “C-Note” Cunningham**: professional musician (40+ years) and music instructor (25+ years) in Philadelphia and the surrounding suburbs. He teaches drums, guitar, bass and beginner piano.

## Features

- Playable guitar strings in the hero: sweep your cursor across them.
- A vinyl turntable you can grab and spin.
- The **Jam Room**: drum pads, a piano, guitar chords and a drum-and-bass groove machine. All the sound is generated live in the browser with the Web Audio API, with no audio files.
- Free trial lesson "ticket", contact details and an email booking form.

It's plain HTML, CSS and JavaScript with no build step and no dependencies. Fonts load from Google Fonts.

## Run it locally

Open `index.html` in any modern browser.
